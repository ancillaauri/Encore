## Encore 0.9.3 (beta), test build 24: a tour of Encore in setup

### What's changed
- **First-run setup is now a short tour** (7 quick pages), so new users find everything:
  1. Welcome and where recordings are saved
  2. Video
  3. Sound
  4. What to record: Follow, a monitor, or Select Application
  5. Game detection ("Made for games"), with a switch
  6. Echoes ("Never miss a moment"), with a switch and length
  7. You're all set: the handy hotkeys, the tray, Do not disturb, and Start with Windows
- **Settings → Games** reads more simply.
- Run it any time: ≡ → Help → Run Setup Again.

### Install
Update from inside Encore (≡ → Help → Update to 0.9.3).
