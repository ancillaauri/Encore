# Encore

A lightweight game recorder for Windows 11.

- Manual recording and instant replay
- Record a single game window or the whole desktop
- Separate audio tracks: full mix, microphone, and one per app (game, music, browser, voice chat)
- GPU encoding on NVIDIA, AMD and Intel

Status: early development. See FEATURES.md for what is built and what is planned.

## Install

Download the latest `Encore_x.y.z_x64-setup.exe` from Releases and run it.
The installer is not code-signed yet, so Windows may show "Windows protected your PC" the first
time: click **More info**, then **Run anyway**.
