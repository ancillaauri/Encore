## Encore 0.8.4 (beta), test build 20: centred monitors

### What's changed
- Your monitors are now centred on the page, with **Follow** just to their left.
- The **Game** tile is gone. Game detection is the switch at the top; when it arrives, games it
  finds will show up as tiles beside Select Application so you can see and lock them.
- From 0.8.3: the new top area (switches, record button, status).

### Install
Update from inside Encore (≡ → Help → Update to 0.8.4).
